Choose a workload from the
[benchmark guides](https://github.com/starwey604/wirelink/blob/main/benchmarks/README.md):

- Deterministic models check owner progress, message age and application retries.
- Host microbenchmarks measure kernel, codec, framing and storage costs.
- Firmware and transport tools measure the selected board and physical link.

For each measurement, record the source revisions, WLC contract, generated
artifacts, hardware, clock and cache settings, compiler, optimization, LTO,
commands, repetition count and complete raw output. Report useful payload
throughput, latency distributions and active CPU separately.

Use separate instrumented CPU runs and uninstrumented latency/throughput runs.
Compare matched workloads and retain the build and capture inputs alongside
results. The [collection procedure](https://github.com/starwey604/wirelink/blob/main/benchmarks/SPEC.md)
defines manifests and comparisons.
