Wirelink's benchmarks are reproduction guides, not guarantees. This page records representative runs by hand after a real measurement, and every entry states the full environment. To re-run a benchmark yourself, start from the [benchmark guides](https://github.com/starwey604/wirelink/tree/main/benchmarks).

:::note[Single runs, not guarantees]
Each table is one run on one machine. Clock frequency, thermal state, toolchain and background load all move the numbers. Treat them as observations, not performance commitments.
:::

## How to record a run

Add one section per run and include every field:

- Date and target (host, or ESP32-S3 DevKitC).
- Hardware: CPU or board, clock, cache and memory configuration.
- Source: Wirelink commit, and WLC version plus codegen contract.
- Toolchain and build flags: compiler, optimization, LTO on or off.
- The exact command, and the repetition count or sample size.
- The result table.
