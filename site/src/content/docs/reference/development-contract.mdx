Wirelink runs typed messages and RPC through one allocation-free C11 kernel.
The application provides storage, monotonic time and one owner for admission,
steps, handlers and terminal callbacks.

The kernel holds four outbound calls, four reply snapshots and one ordinary
message snapshot. Accepted input is encoded before admission returns. Each
accepted call produces one terminal callback; response views are borrowed
until that callback returns.

I/O producers publish packets and completion through a C-owned packet port.
There are two RX units and one physical TX lease. CONSUMED permits source reuse;
DRAINED ends physical transfer ownership. Shutdown closes admission, stops and
joins I/O, then processes remaining completion before storage is released.

Read the [kernel API](https://github.com/starwey604/wirelink/blob/main/docs/static-endpoint-kernel-api.md)
for scheduling and ownership details, the
[adapter lifecycle](https://github.com/starwey604/wirelink/blob/main/docs/adapters.md)
for transport integration, and the
[development guide](https://github.com/starwey604/wirelink/blob/main/docs/development-current.md)
for build and test commands.
