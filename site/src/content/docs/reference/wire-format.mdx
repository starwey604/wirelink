> The full wire specification is maintained in Simplified Chinese: [Wire v2 二进制线协议规范](/wirelink/zh-cn/reference/wire-format/) and [docs/wire-format.md](https://github.com/starwey604/wirelink/blob/main/docs/wire-format.md).

Wire v2 combines a 4-byte canonical frame header (`0x57`), fixed little-endian RPC subheaders, Schema-v1 TLV / Positional-v1 payloads, and orthogonal `cobs_stream` / `bus_length16` connectors.
