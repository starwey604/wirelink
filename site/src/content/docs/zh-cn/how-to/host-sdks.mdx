当设备端运行 `wl_kernel_t` 端点时，上位机无需手写解析表或字节序转换代码。通过 `wlc sdk` 工具，编译器可以一次性为你产出完整的 C++20 头文件/静态库包装与原生 nanobind Python 扩展包（含完整 `.pyi` 类型提示）。

## 一键生成 SDK 工程

对同一份 `.wl` 与绑定配置（例如 `calculator.bind.wl`）执行以下命令即可产出独立可编译的 SDK 项目骨架（已内置 `CMakeLists.txt`、`pyproject.toml`、C++ 头文件与 Python 封装）：

```sh
wlc sdk calculator.wl --profile calculator.bind.wl --out-dir ./calculator_sdk
```

- 默认将使用 schema 主干名作为 C++ namespace 与 Python 包前缀（`<name>_sdk`），可用 `--name <custom>` 与 `--package-version <ver>` 定制。
- 若希望更新已有输出目录中的生成文件，传入 `--overwrite`。

## Python 客户端：同步 `Client` 与异步 `AsyncClient`

生成的 Python 分发包自带 `Client`、`AsyncClient` 与底层 `Udp` 传输对象。底层原生扩展运行在独立 I/O 会话线程，不会在等待响应时阻塞整个 Python 解释器的异步事件循环。

| 异常类型 | 父类 | 常见触发场景 |
| :--- | :--- | :--- |
| `WirelinkError` | `Exception` | 所有 Wirelink 运行时异常基类，携带底层 `error` 信息 |
| `RejectedError` | `WirelinkError` | 设备服务端主动返回 `WL_KERNEL_REJECTED`，`error.status` 为业务拒绝码 |
| `RpcTimeoutError` | `WirelinkError`, `TimeoutError` | RPC 在设定的 `timeout` 内未收到响应 |
| `CancelledError` | `WirelinkError` | 在途 RPC 被显式取消 |
| `QueueFullError` | `WirelinkError` | 并发出站槽位已满（对应底层背压 `WL_ERR_WOULD_BLOCK`） |
| `ClosedError` | `WirelinkError` | 尝试在已关闭的客户端实例上发起新操作 |
| `TransportError` | `WirelinkError` | 底层网络或传输链路故障 |
| `CodecError` | `WirelinkError` | 线缆载荷格式损坏或字段编码超出声明上界 |
| `InvalidArgumentError` | `WirelinkError` | 参数类型或取舍范围不符合字段要求 |

完整安装编译流程与测试验证细节可参考 [examples/06_bindings/GUIDE.md](https://github.com/starwey604/wirelink/blob/main/examples/06_bindings/GUIDE.md)。若使用独立 wheel（`python -m build` 产出）安装，目标运行机无需安装 Rust 或 C 编译器，只需要匹配的 Python 运行时。

## C++20 客户端与异步 `Operation<T>`

对于上位机 C++ 服务、机器人主控或 Qt / ROS 节点，生成的 C++20 SDK 依托 `Wirelink::cpp`（结果与错误类型）和 `Wirelink::cpp_host`（独立拥有底层会合线程的 `Session`）：

- **同步调用**: `client.add(request, timeout)` 返回 `wirelink::Result<AddResponse>`，通过无异常的强类型结果值携带数据或错误码。
- **异步句柄**: `client.add_async(request, timeout)` 返回 `wirelink::Result<wirelink::Operation<AddResponse>>`，支持在合适时机等待完成或主动取消。
- **RAII 资源收口**: `Client` 仅支持移动语义（不可拷贝），析构或调用 `client.close()` 时会自动安全排干并停机底层网络会话。
