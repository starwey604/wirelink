先检查 Wirelink/WLC/codegen 都是 0.13，profile 使用 version 2。双方 schema、消息 ID、native/NONE connector、地址/端口应一致。当前 adapter 使用 fixed peer；连接打开只建立本地 I/O，不证明 peer 在线。

确认 source filter、接收 headroom 与网络缓冲。Asio 和 Zephyr UDP 的 socket I/O 都在应用 owner 执行。wait 合并 latched activity、有限 retry hint、kernel 与应用 deadline。

应用阻塞时不能反复报告无条件 runnable。

RPC 超时不说明远端未执行，重试可能再次产生副作用。排查时同时保留两端业务计数、包/字节、错误与原始时间信息，不用旧 ACK/replay 断言。

close 时停止接纳并 join owner/notify producer，quiescent 后再释放 C-owned port。

先用[双进程例程](/wirelink/zh-cn/learn/udp-transport/)检查软件，再记录真实板卡/网络验证。
