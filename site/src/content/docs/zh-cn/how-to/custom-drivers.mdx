同步整帧写入或可自行排队复制的驱动，优先使用默认 `io = embedded`。它内嵌端口、双 RX 槽和所需流缓冲。真正异步借用生成缓冲的 DMA 驱动，使用 `io = external`。

## 先实现一个物理发送钩子

```wl
message Sample @id(10) { uint32 value @id(1); }
node sensor { framing = cobs_crc16; send Sample; recv Sample; }
```

```c
wl_err_t sensor_tx_write(sensor_node_t *self, const uint8_t *data, size_t length) {
  (void)self;
  /* board_write_frame 必须整帧复制/同步完成，或完全拒绝。 */
  return board_write_frame(data, length) ? WL_OK : WL_ERR_WOULD_BLOCK;
}
```

返回 `WL_OK` 后不能继续借用 data。若外设只写入部分字节，应由适配层保存进度，不能把部分成功报告成整帧成功。外设从忙恢复后调用 `sensor_tx_ready(&sensor)`，再由 owner 推进 `sensor_step`。

## 接收字节流与背压

```c
size_t consumed = 0;
wl_err_t error = sensor_rx_feed(&sensor, bytes, length, &consumed);
/* 始终按 consumed 移走已消费前缀；保留尾部，推进后重试。 */
```

RX 槽满会返回 `WL_ERR_WOULD_BLOCK`；不能丢掉尚未消费的尾部，也不能重喂已消费前缀。native 节点则使用 `<node>_rx_packet`，一次传入一个完整规范帧。

最简单的执行方式是 ISR 只将字节放入 FIFO，owner 读取 FIFO、调用 rx_feed、step 和业务函数。业务 handler 始终在 owner step 内运行。

## embedded 关闭顺序

1. 禁止新的 RX 注入，并与中断/生产者完成同步。
2. 调用 `<node>_close`，拒绝新的业务提交。
3. 继续 `<node>_step(now)`，直至 `<node>_quiescent`；期间完成所有在途调用通知。
4. 只有生产者和节点都静止后，才能复用对象或释放外层存储。

## external：挂载已有 port

```wl
node dma_sensor {
  io = external;
  send Sample;
  recv Sample;
}
```

初始化为 `dma_sensor_init(&node, &port)`，静态 handler 首参仍是节点指针。只有显式 `handlers = dynamic` 才追加 `&handlers, user`。

RX 生产者可调用 `wl_packet_rx_push` 复制整帧，或 claim → 填写 → commit 实现零拷贝；失败路径 abort。物理发送的 `submit` 返回：

| 状态 | 所有权动作 |
| --- | --- |
| `WL_PACKET_SENT` | 同步完成，不再借用源缓冲 |
| `WL_PACKET_STARTED` | 保留异步租约；完成后 `wl_packet_tx_publish` 归还 token |
| `WL_PACKET_BUSY` | 未接受数据；恢复后 `wl_packet_activity` 通知 owner |
| `WL_PACKET_FAILED` | 提交失败，不保留引用 |

异步驱动停止必须同时终止 RX 写入并归还 TX 租约；仅调用 `wl_packet_stop` 不能代替硬件停机。UDP 适配器的接收存储还需保留超过最大合法数据报的 1 字节检测空间。

现有 UDP 服务把适配器 service 与内核 step 放在一个 owner 中：

{/* [docs:udp_host_step] */}
```cpp
wl_err_t example_udp_step(example_udp_t *udp, wl_kernel_t *core, uint32_t now) {
  try {
    const auto error = udp->adapter->service();
    const auto advanced = wl_kernel_step(core, now, 16);
    return error == WL_OK ? advanced : error;
  } catch (...) { return WL_ERR_IO; }
}
```
{/* [/docs:udp_host_step] */}

UART ISR/DMA、USB 和主机 UDP 的完整实现见 `adapters/`。external 流式驱动自行组合 `wl_packet_stream_t`，生成代码不再输出独立 transport C 文件。
