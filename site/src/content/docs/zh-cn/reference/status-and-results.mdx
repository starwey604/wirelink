接纳返回 `wl_err_t`：`WL_OK` 创建调用，失败不创建调用或后续回调。第五个并发 start 返回 `WL_ERR_WOULD_BLOCK`；终态后 handle 失效。

| RPC outcome | status 含义 |
| --- | --- |
| `WL_KERNEL_SUCCESS` | `WL_OK`；响应已解码 |
| `WL_KERNEL_REJECTED` | 非零有符号业务 status |
| `WL_KERNEL_LOCAL_ERROR` | 本地 `wl_err_t` |
| `WL_KERNEL_TIMED_OUT` | `WL_ERR_TIMEOUT` |
| `WL_KERNEL_CANCELLED` | `WL_ERR_CANCELLED` |
| `WL_KERNEL_CLOSED` | `WL_ERR_INVALID_STATE` |

成功数据仅借用到回调返回，需要保留则先复制。本地终态不证明远端回滚或物理 TX 完成；普通发送报告本地接纳/I/O 推进，不报告对端确认。

[API 参考](https://github.com/starwey604/wirelink/blob/main/docs/kernel-api-cn.md#terminal-results)集中维护完整返回/生命周期合同。[安装类型](https://github.com/starwey604/wirelink/blob/main/include/wirelink/types.h)定义本地错误字面量，codec 错误是独立域。SDK close 抛出 `ClosedError`，显式原生 cancel 抛出 `CancelledError`，asyncio task cancel 抛出 `asyncio.CancelledError`。
