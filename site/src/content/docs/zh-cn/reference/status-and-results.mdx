`wl_err_t`、`wl_kernel_outcome_t`、`wl_packet_submit_t` 使用固定 int32_t；短枚举消费者也保持 C ABI。WL_OK 为 0，通用错误为负。

业务拒绝 status 保留原始有符号值，需和本地错误 outcome 一起判读。

| RPC outcome | 意义 |
| --- | --- |
| WL_KERNEL_SUCCESS | 匹配响应并成功解码 |
| WL_KERNEL_REJECTED | 远端业务拒绝，status 是业务码 |
| WL_KERNEL_LOCAL_ERROR | 本地失败，status 是 wl_err_t |
| WL_KERNEL_TIMED_OUT | 本地截止时间到达 |
| WL_KERNEL_CANCELLED | 本地取消 |
| WL_KERNEL_CLOSED | 连接关闭 |

| 常用错误 | 意义 |
| --- | --- |
| WL_ERR_WOULD_BLOCK | 有界容量背压，稍后按 readiness 重试 admission |
| WL_ERR_QUEUE_FULL | 外部命令队列满 |
| WL_ERR_NOT_SUPPORTED | 平台能力/旧帧类型不支持 |
| WL_ERR_IO | 确定性 I/O 失败 |
| WL_ERR_REENTRANT | 禁止的递归 owner 操作 |
| WL_ERR_ID_EXHAUSTED | 安全关闭后以新实例重建 |
| WL_ERR_CORRUPT_PAYLOAD | 元数据/业务体非法 |

成功 admission 后只有一个终态；失败 admission 无未来 callback。普通 send 只有本地接纳/物理 I/O 进展，不产生远端 ACK。

取消/超时不回滚远端。公开 codec 错误仍独立于上述执行结果，完整符号见安装头。
