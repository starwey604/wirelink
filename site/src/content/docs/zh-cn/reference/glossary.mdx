| 术语 | 当前含义 |
| --- | --- |
| owner | 执行 core/codec/业务的唯一上下文 |
| producer | 串行发布 I/O/completion 的上下文 |
| admission | 编码/快照成功，占有有界容量 |
| borrowed view | callback 内有效，跨边界需要复制 |
| owned value | 内含有界数据的可保存值 |
| instance/operation | 通信匹配身份，不是认证或业务幂等键 |
| CONSUMED | 结束源内存借用 |
| DRAINED | 结束物理传输 |
| quiescent | 内核/port 无残留所有权，外部还需实际 producer 退出证明 |
| job ID | 应用为长任务定义的身份 |

旧 replay/TTL、ACK/ARQ、deferred token 和通用 service/policy 不是当前内核能力。
