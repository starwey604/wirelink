从[基准指南](https://github.com/starwey604/wirelink/blob/main/benchmarks/README-cn.md)选择需要的工作负载：

- 确定性模型检查 owner 推进、消息年龄与应用重试。
- Host 微基准测量 kernel、codec、framing 与存储开销。
- 固件及传输工具测量选定开发板与物理链路。

每次测量记录源码版本、WLC contract、生成工件、硬件、主频、cache 配置、编译器、优化参数、LTO、命令、重复次数及完整 raw 输出。分别报告有效 payload 吞吐、延迟分布与 active CPU。

CPU 插桩与无插桩延迟/吞吐使用独立轮次。比较相同工作负载，并随结果保留构建与采集输入。[采集规范](https://github.com/starwey604/wirelink/blob/main/benchmarks/SPEC-cn.md)定义 manifest 与比较方式。
