Wirelink 使用一个无动态分配的 C11 kernel 推进类型化消息与 RPC。应用提供存储、单调时间以及负责接纳、step、handler 和终态回调的唯一 owner。

kernel 持有四个 outbound call、四份 reply snapshot 和一份普通消息 snapshot。接纳成功返回前完成输入编码。每个已接纳调用交付一次终态回调，响应视图借用到回调返回。

I/O producer 通过 C 持有的 packet port 发布包与 completion。port 有两个 RX unit 和一笔物理 TX lease。CONSUMED 允许复用源内存，DRAINED 结束物理传输所有权。

关闭时停止接纳，停止并 join I/O，处理剩余 completion 后释放存储。
