Wirelink 在 C11 核心中从不使用异常，所有 API 均通过确定性的 `wl_err_t` 与 `wl_rpc_outcome_t` 向上层汇报状态，同时可用 `wl_err_str(err)` 将整数错误码转为只读 ASCII 描述串。

## RPC 终态枚举（`wl_rpc_outcome_t`）

当异步 RPC 完成 callback（`done`）被调度触发时，首先应检查 `result.outcome` 以分辨「远端业务响应」还是「本地链路/契约结果」：

| 枚举常量 | 含义 | `result.status` 内容 |
| :--- | :--- | :--- |
| `WL_RPC_SUCCESS` | 成功收到远端有效响应并完成解码 | `0`；响应结构体指针非空，有效至回调返回 |
| `WL_RPC_REJECTED` | 远端业务 handler 返回了非零状态码主动拒绝 | 远端返回的非零 `int32_t` 业务状态码 |
| `WL_RPC_LOCAL_ERROR` | 发送失败或响应包载荷损坏、解码失败 | 对应的本地 `wl_err_t` 错误码 |
| `WL_RPC_TIMED_OUT` | 在预设 `timeout` 节拍到期前未收到应答 | `WL_ERR_TIMEOUT` |
| `WL_RPC_CANCELLED` | 调用方提前成功发起了 `wl_endpoint_cancel` | `WL_ERR_CANCELLED` |
| `WL_RPC_CLOSED` | 本地执行 `wl_node_close` 停机排干期间收尾 | `WL_ERR_INVALID_STATE` |

## 核心错误码（`wl_err_t`）

以下分类列出了 [src/types.c](https://github.com/starwey604/wirelink/blob/main/src/types.c) 定义的全部 26 个核心返回值：

| 分类 | 状态码 | 含义说明 |
| :--- | :--- | :--- |
| 正常 | `WL_OK` | 操作成功完成 |
| 弹性与流控 | `WL_ERR_WOULD_BLOCK` | 发包队列、RPC 并发槽位或 RX 环暂满，非错误，应稍后重试 |
| 弹性与流控 | `WL_ERR_NO_DATA` | 非阻塞轮询或 FIFO 读取当前无可用数据 |
| 弹性与流控 | `WL_ERR_BUSY` | 外设或资源正忙（通常伴随异步就绪唤醒通知） |
| 弹性与流控 | `WL_ERR_QUEUE_FULL` | 目标队列或固定容量槽位已满 |
| 弹性与流控 | `WL_ERR_NO_SPACE` | 环形缓冲区连续可写空间不足 |
| 参数与状态 | `WL_ERR_INVALID_ARG` | 空指针、`timeout == 0` 或越界输入参数 |
| 参数与状态 | `WL_ERR_INVALID_STATE` | 对象处于已关闭、停机中或生命周期不匹配状态 |
| 参数与状态 | `WL_ERR_NOT_INITIALIZED` | 使用前尚未完成 `init` 初始化 |
| 参数与状态 | `WL_ERR_REENTRANT` | 违背单所有权或非重入契约（例如在回调内再次调用 `step`/`close`） |
| 参数与状态 | `WL_ERR_NOT_FOUND` | 句柄失效、已过期或对应令牌实例不存在 |
| 参数与状态 | `WL_ERR_NOT_SUPPORTED` | 未启用的 `route_id`、不支持的帧 `kind` 或功能 |
| 容量与存储 | `WL_ERR_NO_MEM` | 静态配置池内存不满足需求 |
| 容量与存储 | `WL_ERR_BUF_TOO_SMALL` | 提供的编码或读取缓冲区小于所需尺寸 |
| 容量与存储 | `WL_ERR_FRAME_TOO_LONG` | 单帧长度超过物理上限（> 2052 B 规范帧） |
| 容量与存储 | `WL_ERR_PAYLOAD_TOO_LONG` | 载荷超出配置声明的最大上界 |
| 线缆与编解码 | `WL_ERR_BAD_FRAME` | 帧魔数非 `0x57`、零路由 ID 或帧头结构不合法 |
| 线缆与编解码 | `WL_ERR_COBS_DECODE` | COBS 零分隔符逃逸码破坏，流连接器自动弃包重同步 |
| 线缆与编解码 | `WL_ERR_CRC` | CRC-16/CCITT 校验不匹配，帧已被丢弃 |
| 线缆与编解码 | `WL_ERR_CORRUPT_PAYLOAD` | TLV 字段缺失、UTF-8 校验失败、零会话号等载荷损坏 |
| 线缆与编解码 | `WL_ERR_PROTOCOL_VERSION` | 协议版本不兼容或不受支持 |
| 传输与生命周期 | `WL_ERR_IO` | 底层外设、串口或 Socket 硬件 I/O 错误 |
| 传输与生命周期 | `WL_ERR_TX_FAILED` | 物理发送失败（如外设发布 `WL_PACKET_TX_ERROR`） |
| 传输与生命周期 | `WL_ERR_TIMEOUT` | 等待响应超时 |
| 传输与生命周期 | `WL_ERR_CANCELLED` | 事务已被取消 |
| 传输与生命周期 | `WL_ERR_ID_EXHAUSTED` | 会话或序列号生成空间耗尽 |
