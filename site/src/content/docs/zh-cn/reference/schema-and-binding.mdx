当前 WLC/codegen 为 0.13，SDK binding API 为 3。公开 schema 字段值域与 wire 保留，执行选择使用显式 profile version 2。

## `.wl`：消息定义

`.wl` 文件用 `version` 声明兼容版本，然后定义 message 和 enum。

```text
version 1;

enum MotorMode @id(1) {
  MOTOR_MODE_DISABLED = 0;
  MOTOR_MODE_CURRENT = 1;
}

message MotorCommand @id(16) {
  required uint32 operation_id @id(1);
  required MotorMode mode @id(2);
  optional fixed32 target_milliamps @id(3);
  optional bytes<64> vendor_extension @id(4);
}
```

- `version` 只用于 WLC 兼容性检查，不写入 payload。
- message 和 enum 的 `@id(n)` 是非零 16 位声明编号；旧写法 `= n` 完全等价。
- message 编号就是链路 DATA 包里的 `message_id`。enum 编号只是编译器符号。
- 删除的 message、enum、field、enum value 编号永久保留，不能重新分配。

### 字段基数

| 写法 | 含义 |
| --- | --- |
| `required type name @id(n);` | 必须出现；缺失时解码返回 `WL_CODEC_ERR_MISSING_REQUIRED_FIELD` |
| `optional type name @id(n);` | 可以缺失；生成 `has_` 标志 |
| `repeated type name @id(n);` | 任意数量；解码需要调用方提供数组 |
| `packed type name[N] @id(n);` | 固定 N 个数值，内联存储 |
| `required packed type name[N] @id(n);` | 固定 N 个数值，且必须出现 |

`required` 表示单个必须出现的值，禁止与默认值或 `repeated` 组合。需要固定数量的必填向量时，用 `required packed`。

### 内建类型

| 类型 | C 表示 | 说明 |
| --- | --- | --- |
| `bool` | `bool` | 只取 0 或 1 |
| `uint8`…`uint64` | 精确宽度无符号整数 | |
| `int8`…`int64` | 精确宽度有符号整数 | |
| `fixed32`、`fixed64` | `uint32_t`、`uint64_t` | 固定 4/8 字节，大端 |
| `float32`、`float64` | `float`、`double` | IEEE-754，大端 |
| `bytes<MAX>` | `wl_codec_bytes_t` | 最多 MAX 字节 |
| `string<MAX>` | `wl_codec_string_t` | 最多 MAX 字节的 UTF-8 |

`bytes<MAX>` 和 `string<MAX>` 的 `MAX` 取值为 1…65535，按编码字节计数，不含 NUL。编码越界返回 `WL_CODEC_ERR_INVALID_VALUE`，UTF-8 错误返回 `WL_CODEC_ERR_UTF8`。

v1 不支持 map、`oneof`、service 或 extension。嵌套 message 最大深度为 8，直接或间接递归会被拒绝。

## Profile v2

普通路由显式声明 send/direct，RPC 使用同步 typed handler 和 managed tagged 编码。旧 latest/fifo/reliable/guarantee/mapped/deferred DSL 明确拒绝，不自动翻译。

普通 PositionalV1 codec 可显式选择，RPC positional 需要迁移。

```text
profile version 2;
endpoint { envelope=native_packet; }

direct Telemetry {
  delivery = unreliable;
}

send Telemetry { delivery=unreliable; }
```

## 生成

无 profile 只生成 public codec。带 profile 的单 `wirelink_wlc_generate` target 提供静态路由、消息容量和选定 connector。

旧 separate-runtime 输出与 stale runtime/advanced/bindings 目录必须迁移到新目录，不能混合接口。
