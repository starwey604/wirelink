单 owner 执行 admission、step、cancel、handler 和 terminal callback。core 不创建线程，也不读时钟。

I/O callback/ISR 只向 C-owned packet port 或 staging FIFO 发布状态。

C11 atomic 存储由 C 持有，C++ 使用 opaque pointer，不能拿 std::atomic 对象替代其布局。固定四 call、四 reply、一 ordinary snapshot 不在外层复制另一套 RPC 表。

可选 Executor 有 32 命令槽，每最多八条命令后推进 kernel。work 与 stop 拒绝都在 owner。

owner callback 可以 `request_stop`，join/销毁由外部调用方负责。外部关闭等待 submitter、停止并 join I/O/owner 后释放状态。
