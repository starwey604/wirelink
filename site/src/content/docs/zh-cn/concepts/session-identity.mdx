端点初始化时从显式 source 获取新的非零 communication instance。平台随机源或持久分配器负责唯一性，失败不能回退成时钟或生产固定 ID。

比较一个 previous 只能做局部检查，不能证明全局唯一。

RPC 使用 client instance 和不回绕的 operation 匹配响应，旧响应不能结束新调用。operation/generation 或 port sequence 耗尽时，需要真实关闭、quiescence 和新 instance。

普通 ring cursor 可回绕。

通信身份仅用于匹配消息。认证与幂等需要各自的业务机制。重复请求可以重新执行业务；需要去重的产品必须携带业务 ID 并自行定义状态生命周期。

测试 fixture 的递增身份仅用于隔离模拟。
