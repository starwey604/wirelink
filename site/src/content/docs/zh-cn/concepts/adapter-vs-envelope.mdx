kernel 接受 canonical native/NONE ordinary DATA。profile v2 选定 native/NONE、COBS/CRC16 或 length16/NONE。adapter 映射物理 I/O，codec 和业务留在 owner。

双方带外约定 schema、ID 和 connector，不自动协商。

USB/datagram 保留单元边界，读容量严格大于合法 frame。UART 使用 COBS/CRC16 与 C-owned staging FIFO，真实失字节时 abort/resync，普通背压则暂停/恢复。

CONSUMED 和 DRAINED 含义分开。DMA 等实际 buffer 归还，IRQ 要真实 TX-complete，serial/poll 要物理 idle query。

当前 Zephyr CDC 缺该能力时明确拒绝。USB 边界故障要真实 reset/reconfigure，单纯 reopen 不恢复。
