handler 请求和完成 callback 的响应视图借用 core/RX 存储，指针只在 callback 内有效。直接复制 view 只复制指针，不能延长数据生命周期。

需要保存响应时，在 callback 返回前用生成的公开 `*_value_from_view` 复制，并检查转换结果。owned `*_value_t` 把有界字符串、字节、presence 和 length 保存在值内部，可以在端点关闭后读取。

长度可包含 NUL，不能用 strlen 代替。

C++/Python SDK 的 Operation 在借用期完成复制，交付给用户的是拥有型结果。C SDK 的 borrowed callback 仍需应用按上述规则保存。

没有终态 inspect/release 槽或 deferred reply token。
