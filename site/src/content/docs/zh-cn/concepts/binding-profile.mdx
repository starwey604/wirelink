当前 0.14 把消息、RPC 与节点配置统一放在 `.wl` 中。原绑定配置的职责由 `node` 接管。

- 用顶层 `rpc Add(AddRequest) -> AddResponse;` 配对请求与响应。
- 在节点内用 `call` / `serve` 明确两端角色，用 `recv` 接收普通消息。
- 用 `framing = native | cobs_crc16 | length16` 选择分帧。
- 用 `import` 组合业务模块，用 `--node` 选择固件角色。

请使用[节点声明指南](/wirelink/zh-cn/concepts/nodes/)与[当前 CLI / CMake 用法](/wirelink/zh-cn/concepts/wlc-and-cmake/)。
