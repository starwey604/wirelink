在 Wirelink 中，消息数据结构、RPC 配对与节点配置统一声明在 `.wl` 文件中：

- 用顶层 `rpc Add(AddRequest) -> AddResponse;` 配对请求与响应。
- 在 `node` 内用 `call` / `serve` 明确双向调用角色，用 `send` / `recv` 声明单向消息。
- 用 `framing = native | cobs_crc16 | length16` 选择物理链路分帧。
- 所有节点在 C 侧统一提供 `<node>_bind_sync`（同步发送函数）与 `<node>_bind`（异步/零拷贝传输），无需在 `.wl` 中指定 I/O 模式。
- 用 `import` 组合多业务模块，用 `--node` 选择要生成的固件角色。

详细用法请查阅[节点声明指南](/wirelink/zh-cn/concepts/nodes/)与[WLC / CMake 集成指南](/wirelink/zh-cn/concepts/wlc-and-cmake/)。
