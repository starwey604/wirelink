当前 board 示例为 samples/zephyr/udp_peer，和 desktop peer 共用 schema/profile。启用选定 Ethernet/Wi-Fi driver、IPv4、网络缓冲及真实初始化熵源，再启动 Wirelink adapter。

示例默认地址 192.0.2.1/192.0.2.2 属于文档地址，需要按测试网络配置。server/client 端口与 fixed peer 必须显式一致。

模拟配置 sim.conf 的测试随机源不能用于生产通信身份。

```sh
west build -s /path/to/wirelink/samples/zephyr/udp_peer -b YOUR_BOARD \
  -d build/udp-server -- -DWIRELINK_WLC_EXECUTABLE=/path/to/wlc
```

使用匹配的本地 WLC 0.13，按板卡配置 devicetree/Kconfig。native/QEMU 软件检查与板卡 build 不证明真实 PHY/网络性能；物理运行需另录硬件、配置、源码、ELF/bin 和采集。
