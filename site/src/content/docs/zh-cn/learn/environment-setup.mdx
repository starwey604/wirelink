## 先构建 core

在 Wirelink 根目录准备 C11 编译器和 CMake 3.21+。默认 loopback 使用已检入的生成 C，不需要 WLC 或硬件。

```sh
cmake -S . -B build/core -DCMAKE_BUILD_TYPE=Release
cmake --build build/core --parallel
ctest --test-dir build/core --output-on-failure
```

## 为自己的消息准备 WLC

生成教程与项目需要匹配的 Wirelink 0.13.0、WLC 0.13.0 / 契约 0.13。WLC 是独立源码仓库，Rust/Cargo 只用于构建这个工具：

```sh
cargo build --release --locked --manifest-path /path/to/matching-wlc/Cargo.toml
/path/to/matching-wlc/target/release/wlc --version
/path/to/matching-wlc/target/release/wlc codegen-contract
```

预期输出 `wlc 0.13.0` 和 `0.13`。将工具绝对路径传给 `WIRELINK_WLC_EXECUTABLE`。host/桌面 adapter 另需 C++20 与 standalone Asio；Python SDK 源码构建需 Python 3.10+ 和开发头文件。

继续[发送遥测](/wirelink/zh-cn/learn/getting-started/)或[发起 RPC](/wirelink/zh-cn/learn/request-a-result/)。完整[安装说明](https://github.com/starwey604/wirelink/blob/main/docs/installation-cn.md)集中说明平台依赖；已有应用使用[安装后 CMake 集成](/wirelink/zh-cn/learn/external-cmake-project/)。
