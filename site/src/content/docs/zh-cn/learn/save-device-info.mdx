完成八次查询，关闭两端后继续读取保存的名称。预期输出 `bounded UTF-8/NUL response copied before callback exit and retained after close`。

在 Wirelink 根目录使用匹配 WLC 0.13.0 / 契约 0.13：

```sh
cmake -S . -B /tmp/wirelink-docs-tutorials -DCMAKE_BUILD_TYPE=Release \
  -DWIRELINK_BUILD_WLC_EXAMPLES=ON \
  -DWIRELINK_WLC_EXECUTABLE=/absolute/path/to/matching-wlc
cmake --build /tmp/wirelink-docs-tutorials --parallel \
  --target wirelink_device_info_demo
ctest --test-dir /tmp/wirelink-docs-tutorials --output-on-failure \
  -R '^wirelink_device_info_demo$'
/tmp/wirelink-docs-tutorials/examples/02_device_info/wirelink_device_info_demo
```

## 复制数据，不是 view 指针

completion 传入的 `const info_response_t *` 仅借用到回调返回。例程调用 `info_response_value_from_view`，检查 `WL_CODEC_OK`，将有界字符串复制到 `info_response_value_t`。只复制 view 指针仍然依赖端点存储。

保存名称的 length 为 `11`，字节为 `workbench\0x`；内嵌 NUL 不结束逻辑字符串。bound 按 UTF-8 字节而非字符计数。例程在两端关闭、物理 lease quiescent 后检查数据。

查看[可构建复制 helper 与源码](https://github.com/starwey604/wirelink/blob/main/docs/tutorial-rpc-values-cn.md)。下一篇：[容量与取消](/wirelink/zh-cn/learn/async-rpc/)。
