[English](https://github.com/starwey604/wirelink/blob/main/docs/installation.md).

纯 core 使用 ISO C11、CMake 3.21+。host Executor、C++ Session、桌面 adapter 需要 C++20；MSVC 的 C 源使用 `/experimental:c11atomics`，原子存储由 C 持有，C++ 不假定 `std::atomic` ABI。

benchmark 工具使用 Python 3.11+，其余测试依对应 CMake 声明。

默认 core 和 checked-in bare-metal 示例不需要 WLC：

```sh
cmake -S . -B build/core -DCMAKE_BUILD_TYPE=Release
cmake --build build/core --parallel
ctest --test-dir build/core --output-on-failure
cmake --install build/core --prefix /absolute/prefix
```

生成需要从匹配的独立源码构建 **WLC 0.13.0 / codegen 0.13**。Rust/Cargo 只用于构建编译器，不进入 C core。

编译器模板保留 LF。

```sh
cargo build --release --locked --manifest-path /path/to/matching-wlc/Cargo.toml
/path/to/matching-wlc/target/release/wlc --version
/path/to/matching-wlc/target/release/wlc codegen-contract
```

预期输出 `wlc 0.13.0` 和 `0.13`；`WIRELINK_WLC_EXECUTABLE` 使用该绝对路径。helper 校验 compiler/生成 manifest，不 bootstrap 旧发布版，也不假定已有 0.13 发布包。

codegen 版本描述接口/布局，不是 wire 版本。

```sh
cmake -S . -B build/tutorials -DCMAKE_BUILD_TYPE=Release \
  -DWIRELINK_BUILD_WLC_EXAMPLES=ON \
  -DWIRELINK_WLC_EXECUTABLE=/absolute/path/to/matching-wlc
cmake --build build/tutorials --parallel
ctest --test-dir build/tutorials --output-on-failure
```

安装后用 `find_package(Wirelink 0.13 EXACT CONFIG REQUIRED)`，设置 `CMAKE_PREFIX_PATH=/absolute/prefix`。基础 C 包不要求 C++ compiler；可选 host/adapter component 必须已构建/安装，消费者 project 需启用 CXX。

Asio UDP 使用 standalone Asio，当前本地验证版本 1.38.1，commit `bbecff21a23b97c34641f0f1f08b28c91b9c77cf`。设置 `WIRELINK_ASIO_INCLUDE_DIR=/absolute/path/to/asio/asio/include` 并启用 `WIRELINK_BUILD_ASIO_UDP_ADAPTER=ON`；UDP 示例还需 `WIRELINK_BUILD_PLATFORM=ON`。

Astrial 使用 `WIRELINK_ASTRIAL_SOURCE_DIR`，native USB 另需 backend 的 libusb 依赖，均不进入 C core。

继续阅读[迁移](/wirelink/zh-cn/reference/development-contract/)、[遥测教程](/wirelink/zh-cn/learn/getting-started/)与[开发检查](https://github.com/starwey604/wirelink/blob/main/docs/development-current.md)。本地 Linux 通过不代表远程 Windows/macOS、manylinux 或硬件检查已执行。
