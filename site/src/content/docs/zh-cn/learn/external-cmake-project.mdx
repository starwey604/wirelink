在 Wirelink 根目录安装 core，再从包含你自己的 `main.c` 的独立项目消费。构建前配置安装 prefix，使 `wirelink.pc` 同样记录正确路径。

```sh
cmake -S . -B build/install-core -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_INSTALL_PREFIX=/absolute/prefix -DCMAKE_INSTALL_LIBDIR=lib
cmake --build build/install-core --parallel
cmake --install build/install-core
```

```cmake
cmake_minimum_required(VERSION 3.21)
project(my_device LANGUAGES C)
find_package(Wirelink 0.13.0 EXACT CONFIG REQUIRED)
add_executable(app main.c)
target_link_libraries(app PRIVATE Wirelink::wirelink)
```

```sh
cmake -S /path/to/my-device -B build/my-device \
  -DCMAKE_PREFIX_PATH=/absolute/prefix
cmake --build build/my-device --parallel
```

基础 target 只需要 C。可选 host/adapter component 需要 CXX，且必须在安装构建中启用。生成类型化 route 时，将 `WIRELINK_WLC_EXECUTABLE` 设为匹配 WLC 0.13.0，使用 `wirelink_wlc_generate(TARGET ... SCHEMA ... PROFILE ...)`；只生成 codec 则使用 `wirelink_wlc_generate_codec`。

[pkg-config 与安装后消费命令](https://github.com/starwey604/wirelink/blob/main/docs/development-cn.md#验证-installed-consumer)覆盖生成和可选 component。[WLC 指南](https://github.com/starwey604/wlc/blob/main/docs/codegen-cn.md)解释 import 与 provenance。
