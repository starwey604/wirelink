运行本机 UDP client/server，输出 `20 + 22 = 42` 与 `telemetry sample=...`。准备 C11/C++20、匹配 WLC 0.13.0 / 契约 0.13、standalone Asio，并允许本机 UDP socket。在 Wirelink 根目录运行：

```sh
cmake -S . -B /tmp/wirelink-docs-udp -DCMAKE_BUILD_TYPE=Release \
  -DWIRELINK_BUILD_WLC_EXAMPLES=ON -DWIRELINK_BUILD_ASIO_UDP_ADAPTER=ON \
  -DWIRELINK_BUILD_PLATFORM=ON \
  -DWIRELINK_ASIO_INCLUDE_DIR=/absolute/path/to/asio/include \
  -DWIRELINK_WLC_EXECUTABLE=/absolute/path/to/matching-wlc
cmake --build /tmp/wirelink-docs-udp --parallel \
  --target udp_peer_client udp_peer_server
ctest --test-dir /tmp/wirelink-docs-udp --output-on-failure -R '^wirelink_udp_peer$'
```

```sh
# Terminal 1
/tmp/wirelink-docs-udp/examples/05_zephyr_udp/udp_peer_server 127.0.0.1 49101 127.0.0.1 49100
# Terminal 2
/tmp/wirelink-docs-udp/examples/05_zephyr_udp/udp_peer_client 127.0.0.1 49100 127.0.0.1 49101
```

## 将 I/O 与 core 放在同一 owner

C 持有 port、两份 `2053` 字节 RX unit 和生成 kernel，最大 datagram 为 `2052` 字节。薄 C++ helper 拥有 Asio socket/wait，但不创建 owner 线程；每轮先 service I/O，再 step kernel。

`example_udp_wait` 用 `wl_kernel_ready` 查询 readiness/最早 deadline，扣除已耗时间，再交给 adapter 的锁存等待。server 还用下一次 20 毫秒 telemetry 尝试限制等待。这些时间都使用毫秒，不是 RAM 教程的循环 tick。

同一 owner close kernel、停止 socket、step 并确认 quiescent 后释放 helper。若加入外部 worker，还需确认退出。查看[完整 owner loop 与 helper 源码](https://github.com/starwey604/wirelink/blob/main/docs/tutorial-integration-cn.md)，再按[传输合同](/wirelink/zh-cn/reference/transports/)替换 UART/USB；板卡网络见 [Zephyr peer](/wirelink/zh-cn/learn/zephyr-udp-subscriber/)。
