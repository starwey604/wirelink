发送 12 条普通消息，输出 `12 ordinary telemetry messages received; both endpoints quiescent`。

在 Wirelink 根目录使用匹配 WLC 0.13.0 / 契约 0.13。先[配置工具](/wirelink/zh-cn/learn/environment-setup/)。

```sh
cmake -S . -B /tmp/wirelink-docs-tutorials -DCMAKE_BUILD_TYPE=Release \
  -DWIRELINK_BUILD_WLC_EXAMPLES=ON \
  -DWIRELINK_WLC_EXECUTABLE=/absolute/path/to/matching-wlc
cmake --build /tmp/wirelink-docs-tutorials --parallel \
  --target wirelink_telemetry_demo
ctest --test-dir /tmp/wirelink-docs-tutorials --output-on-failure \
  -R '^wirelink_telemetry_demo$'
/tmp/wirelink-docs-tutorials/examples/00_telemetry/wirelink_telemetry_demo
```

## 接纳后复用源值

`telemetry_kernel_send_telemetry` 在返回 `WL_OK` 前完成快照。publisher 立即清空源值，subscriber 在借用回调中检查序号和温度。需要保存的值在返回前复制；遇到 `WL_ERR_WOULD_BLOCK`，由应用保留待发值并稍后重试。

两个 C11 peer 共用一个 owner 和 RAM-copy loopback。一个 tick 是一轮循环，不是毫秒。owner 推进两端 kernel 和传输；关闭时停止保留传输并 step 到两端 quiescent。

查看 [publisher、subscriber 与生命周期说明](https://github.com/starwey604/wirelink/blob/main/docs/getting-started-cn.md)。下一篇：[发起 RPC](/wirelink/zh-cn/learn/request-a-result/)。
