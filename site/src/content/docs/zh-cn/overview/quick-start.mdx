本页将引导你完成两项准备工作：
1. 验证本地 C11 构建环境并运行仓库自带的基础示例。
2. 构建协议编译器 `wlc`，从 `.wl` 文件生成 C 代码并运行对应的示例程序。

---

## 前置要求

开始前请确认本地已安装以下工具：

- **CMake 3.21+** 与支持 **ISO C11** 的编译器（GCC、Clang 或 MSVC）
- **Rust / Cargo**：用于构建协议编译器 `wlc`（若暂未安装，仍可先完成第一步）

---

## 第一步：编译并运行基础示例

仓库中自带了一份无需重新生成代码即可运行的基础示例，适合先验证本地 C 工具链是否正常工作。

<Steps>

1. 克隆仓库并进入根目录：

   ```sh
   git clone https://github.com/starwey604/wirelink.git
   cd wirelink
   ```

2. 配置并构建核心库与示例：

   ```sh
   cmake -S . -B build/core -DCMAKE_BUILD_TYPE=Release
   cmake --build build/core --parallel
   ```

3. 运行本地内存回环示例：

   ```sh
   ./build/core/examples/wirelink_bare_metal_loopback
   ```

</Steps>

终端输出以下内容表示构建与运行正常：

```text
6 bidirectional RPC completions, 2 telemetry messages; both endpoints quiescent
```

## 第二步：构建 `wlc` 并生成第一份 C 代码

在实际项目中，你会先编写 `.wl` 协议文件，再由编译器 `wlc` 生成对应的 C11 节点代码或上位机客户端包。

<Steps>

1. 构建本地 `wlc` 可执行文件：

   ```sh
   cargo build --release --locked --manifest-path wlc/Cargo.toml
   ```

2. 查看示例协议 [`examples/01_rpc/calculator.wl`](https://github.com/starwey604/wirelink/blob/main/examples/01_rpc/calculator.wl)，其中定义了一个远程加法服务以及调用方（`client`）、服务方（`server`）两个角色：

   {/* [docs:calculator_schema] */}
   ```wl
   message AddRequest @id(20) {
     int32 left @id(1);
     int32 right @id(2);
   }
   message AddResponse @id(21) { int32 sum @id(1); }
   rpc Add(AddRequest) -> AddResponse;
   node client { call Add; }
   node server { serve Add; }
   ```
   {/* [/docs:calculator_schema] */}

3. 使用 `wlc compile` 为 `server` 节点生成 C 代码：

   ```sh
   wlc/target/release/wlc compile examples/01_rpc/calculator.wl \
     --node server --out-dir build/my-server
   ```

4. 查看生成的 `build/my-server/` 目录，其中包含以下文件：

   <FileTree>
   - build/my-server/
     - **calculator.h** 消息结构体与节点函数声明，在业务代码中 `#include`
     - **calculator.c** 编解码与节点状态机实现，加入编译列表
     - calculator_manifest.json 构建与版本核对清单
   </FileTree>

5. 使用 CMake 编译并运行该协议对应的完整示例：

   ```sh
   cmake -S . -B build/examples -DCMAKE_BUILD_TYPE=Release \
     -DWIRELINK_BUILD_WLC_EXAMPLES=ON \
     -DWIRELINK_WLC_EXECUTABLE="$PWD/wlc/target/release/wlc"
   cmake --build build/examples --target wirelink_calculator_demo
   ctest --test-dir build/examples -R wirelink_calculator_demo --output-on-failure
   ```

   测试通过后，表示「`.wl` 定义 → `wlc` 代码生成 → C11 编译运行」的完整链路已在本地就绪。

</Steps>

## 接下来的学习路径

完成环境验证后，可以按顺序阅读 6 节实战教程：

1. **[01 编写第一个 `.wl` 并运行服务端](/wirelink/zh-cn/learn/01-loopback-endpoint/)** —— 打开生成的 `calculator.h`，理解生成符号的命名规则，实现服务处理函数与主循环。
2. **[02 单向消息（Telemetry）与 RPC](/wirelink/zh-cn/learn/02-telemetry/)** —— 学习 `send` / `recv` 单向推送，理清它与双向 RPC 的分工与配合方式。
3. **[03 C 语言客户端调用与错误处理](/wirelink/zh-cn/learn/03-rpc-basics/)** —— 在 C 代码中发起 RPC 调用，在回调中区分成功响应与服务端业务拒绝。
4. **[04 字符串、可选字段与多文件组合](/wirelink/zh-cn/learn/04-strings-and-lifetime/)** —— 使用 `string<N>`、`bytes<N>`、`optional` 与 `import`，掌握回调中的结构体拷贝规则。
5. **[05 并发调用、超时取消与发送队列控制](/wirelink/zh-cn/learn/05-concurrency-backpressure/)** —— 处理并发请求、设置调用超时与主动取消，以及应对 `WL_ERR_WOULD_BLOCK`。
6. **[06 接入串口、UDP 与上位机 Python / C++ SDK](/wirelink/zh-cn/learn/06-host-sdk-and-transports/)** —— 配置 UART 串口分帧与 UDP 传输，并生成 Python 与 C++20 上位机客户端进行联调。
