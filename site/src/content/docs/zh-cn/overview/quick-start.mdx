先跑现成回环验证工具链，再为自己的设备生成节点。

## 免硬件运行回环

```sh
cmake -S . -B build/core -DCMAKE_BUILD_TYPE=Release
cmake --build build/core --parallel
./build/core/examples/wirelink_bare_metal_loopback
```

输出 `6 bidirectional RPC completions, 2 telemetry messages; both endpoints quiescent`。仓库带已生成的 demo C，因此这一步不需要 WLC。

## 1. 一份 `.wl` 定义消息与角色

保存为 `calculator.wl`：

{/* [docs:calculator_schema] */}
```wl
message AddRequest @id(20) {
  int32 left @id(1);
  int32 right @id(2);
}
message AddResponse @id(21) { int32 sum @id(1); }
rpc Add(AddRequest) -> AddResponse;
node client { call Add; }
node server { serve Add; }
```
{/* [/docs:calculator_schema] */}

字段默认必选，结构体不需要 `has_left = true`；节点默认 embedded/static，不需手写 port/handlers 装配。

## 2. 按角色生成

使用匹配的本地 WLC 0.14.0：

```sh
wlc compile calculator.wl --node server --out-dir generated
wlc sdk calculator.wl --node client --name calculator --out-dir sdk
```

固件得到 `calculator.h/.c` 和清单，上位机得到可构建的 UDP C++20/Python 工程。多角色本地回环使用 `--all-nodes`。

## 3. 实现服务、物理发送与主循环

{/* [docs:calculator_server] */}
```c
int32_t server_on_add(server_node_t *self, const add_request_t *request, add_response_t *response) {
  (void)self;
  const int64_t sum = (int64_t)request->left + request->right;
  if (sum < INT32_MIN || sum > INT32_MAX) return 1;
  response->sum = (int32_t)sum;
  return 0;
}
```
{/* [/docs:calculator_server] */}

除业务函数外，实现 `server_tx_write`，把完整帧同步写出或复制到自己的发送队列；收包调用 `server_rx_packet`。初始化 `server_init(&server)`，周期推进 `server_step(&server, now_ms)`。物理接口必须遵守[整帧与背压契约](/wirelink/zh-cn/how-to/custom-drivers/)。

已有 UDP 驱动的完整构建示例见 `examples/05_zephyr_udp`；SDK 的可执行联调与 wheel 检查见 `examples/06_bindings`。构建并安装 SDK 后，用 `Client`、`Udp` 与 `RejectedError`：

{/* [docs:python_sdk_client] */}
```python
with Client.connect(Udp(peer=('127.0.0.1', port))) as client:
    saved = client.add(left=20, right=22)
    assert saved.sum == 42
    try:
        client.add(left=2**31 - 1, right=1)
    except RejectedError as error:
        assert error.status == 1
```
{/* [/docs:python_sdk_client] */}

这里 `port` 是实际服务端 UDP 端口。继续[第 01 课](/wirelink/zh-cn/learn/01-loopback-endpoint/)或查看[SDK 构建指南](/wirelink/zh-cn/how-to/host-sdks/)。
