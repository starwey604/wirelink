## 热身：30 秒免硬件体验（无需安装 WLC）

仓库里已经附带了一份预先生成的 C11 节点代码（位于 `examples/kernel/generated/`）。只要你的电脑上有 CMake（3.21+）和 C11/C++20 编译器（GCC 或 Clang），就能直接编译并运行内存回环示例：

```sh
cmake -S . -B build/core -DCMAKE_BUILD_TYPE=Release
cmake --build build/core --parallel
./build/core/examples/wirelink_bare_metal_loopback
```

你会立即看到如下终端输出：

```text
6 bidirectional RPC completions, 2 telemetry messages; both endpoints quiescent
```

这短短一行输出背后，两个纯 C11 节点已经在同一块内存里完成了 **6 次双向并发 RPC 调用（包含正常应答、超时与取消）** 和 **2 条单向遥测消息**，最后排空所有在途状态、优雅停机（`quiescent`）。

## 实战：三步构建你的第一个 RPC 服务

现在，让我们从头写一个“远程加法计算器”协议：MCU 作为服务端（`server`）提供加法计算，并在整数溢出时拒绝请求；另一端（C11 客户端或上位机 Python）作为客户端（`client`）发起调用。

<Steps>

1. **写一份 `calculator.wl` 定义消息与两端角色**

   新建 `calculator.wl`，把请求消息、响应消息、RPC 配对和两个节点角色写在一起：

   {/* [docs:calculator_schema] */}
   ```wl
   message AddRequest @id(20) {
     int32 left @id(1);
     int32 right @id(2);
   }
   message AddResponse @id(21) { int32 sum @id(1); }
   rpc Add(AddRequest) -> AddResponse;
   node client { call Add; }
   node server { serve Add; }
   ```
   {/* [/docs:calculator_schema] */}

   <Aside type="note" title="默认配置省去了什么？">
   - **字段默认必选**：`left`、`right`、`sum` 都是必选字段，生成的 C 结构体里直接是 `int32_t left;`，没有啰嗦的 `has_left`。
   - **节点默认自包含（`embedded + static`）**：默认情况下，`node` 自带端口和收发缓冲区，业务回调通过静态 C 函数名直接链接，无需手写任何初始化装配表。
   </Aside>

2. **用 `wlc` 按角色生成 C11 节点与 Python SDK**

   在仓库根目录下构建本地 `wlc` 编译器（版本 0.14.0），然后分别针对服务端固件和上位机客户端生成代码：

   ```sh
   # 1. 构建本地 WLC 编译器
   cargo build --release --locked --manifest-path wlc/Cargo.toml

   # 2. 为 MCU 服务端生成纯 C11 节点代码（指定 --node server）
   wlc/target/release/wlc compile examples/01_rpc/calculator.wl \
     --node server --out-dir build/server

   # 3. 为上位机生成 Python / C++20 UDP 客户端 SDK（指定 --node client）
   wlc/target/release/wlc sdk examples/01_rpc/calculator.wl \
     --node client --name calculator --out-dir build/calculator-sdk
   ```

   生成后的目录非常清爽：

   <FileTree>
   - build/
     - server/ 固件只需把这一对 .h/.c 加入工程
       - **calculator.h** 生成的メッセージ结构体、server_node_t 与 API 声明
       - **calculator.c** 编解码与服务端节点路由实现
       - calculator_manifest.json 构建校验清单
     - calculator-sdk/ 完整的 C++20 与 Python 扩展工程
       - CMakeLists.txt
       - pyproject.toml
       - include/calculator/client.hpp
       - python/calculator_sdk/
   </FileTree>

   *(提示：如果你想在同一个 C 进程里同时跑 `client` 和 `server` 做本地回环测试，把 `--node server` 换成 `--all-nodes` 即可。)*

3. **实现 1 个业务函数与收发钩子，跑通调用**

   打开生成的 `calculator.h`，你会发现服务端节点 `server_node_t` 只需要你提供两个函数：一个处理加法业务的 `server_on_add`，一个把打包好的帧发出去的 `server_tx_write`。

   <Tabs>
     <TabItem label="MCU 服务端业务 (server.c)">
       实现 `server_on_add`：返回 `0` 表示成功并发送 `response`；返回非零值（如这里的 `1`）表示**业务拒绝**，客户端会收到该状态码：

       {/* [docs:calculator_server] */}
       ```c
       int32_t server_on_add(server_node_t *self, const add_request_t *request, add_response_t *response) {
         (void)self;
         const int64_t sum = (int64_t)request->left + request->right;
         if (sum < INT32_MIN || sum > INT32_MAX) return 1;
         response->sum = (int32_t)sum;
         return 0;
       }
       ```
       {/* [/docs:calculator_server] */}

       接着：
       - 实现 `server_tx_write(self, data, length)` 把整帧字节写到你的物理链路；
       - 收到完整数据包时调用 `server_rx_packet(&server, data, length)`；
       - 初始化 `server_init(&server)` 后，在主循环里周期调用 `server_step(&server, now_ms)`。
     </TabItem>

     <TabItem label="上位机 Python 调用">
       当服务端接入 UDP 适配器运行后（完整可编译双端工程见 [`examples/05_zephyr_udp`](https://github.com/starwey604/wirelink/tree/main/examples/05_zephyr_udp) 和 [`examples/06_bindings`](https://github.com/starwey604/wirelink/tree/main/examples/06_bindings)），在 Python 中即可像调用本地函数一样调用远端 MCU：

       {/* [docs:python_sdk_client] */}
       ```python
       with Client.connect(Udp(peer=('127.0.0.1', port))) as client:
           saved = client.add(left=20, right=22)
           assert saved.sum == 42
           try:
               client.add(left=2**31 - 1, right=1)
           except RejectedError as error:
               assert error.status == 1
       ```
       {/* [/docs:python_sdk_client] */}
     </TabItem>
   </Tabs>

</Steps>
