Admit four calls, block a fifth, cancel one and expire three. Resume transport and complete another request. Expect `four calls, fifth blocked, cancel, three timeouts and recovery passed`.

Use matching WLC 0.13.0 / contract 0.13 from the Wirelink root:

```sh
cmake -S . -B /tmp/wirelink-docs-tutorials -DCMAKE_BUILD_TYPE=Release \
  -DWIRELINK_BUILD_WLC_EXAMPLES=ON \
  -DWIRELINK_WLC_EXECUTABLE=/absolute/path/to/matching-wlc
cmake --build /tmp/wirelink-docs-tutorials --parallel \
  --target wirelink_rpc_lifecycle
ctest --test-dir /tmp/wirelink-docs-tutorials --output-on-failure \
  -R '^wirelink_rpc_lifecycle$'
/tmp/wirelink-docs-tutorials/examples/01_rpc/wirelink_rpc_lifecycle
```

## Retry only work that was not admitted

`WL_ERR_WOULD_BLOCK` on the fifth start creates no call or callback. Retain a handle only after `WL_OK`. Cancel schedules one later terminal; cancelling an expired handle returns `WL_ERR_NOT_FOUND`.

The fixture holds physical TX. One request is leased; the other three expire unsent at tick `2`. On resuming real RAM copying, the cancelled request and the new request both execute, so `effects == 2`. The old response cannot deliver another terminal.

Call slots and physical snapshots have different lifetimes. A logical terminal does not return a USB/DMA lease. Callback code may submit/cancel, but cannot recursively step/close; copy responses before returning.
