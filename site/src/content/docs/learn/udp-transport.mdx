Run desktop UDP client/server peers and print `20 + 22 = 42` plus `telemetry sample=...`. Provide C11/C++20, matching WLC 0.13.0 / contract 0.13, standalone Asio and local UDP socket access. Run from the Wirelink root:

```sh
cmake -S . -B /tmp/wirelink-docs-udp -DCMAKE_BUILD_TYPE=Release \
  -DWIRELINK_BUILD_WLC_EXAMPLES=ON -DWIRELINK_BUILD_ASIO_UDP_ADAPTER=ON \
  -DWIRELINK_BUILD_PLATFORM=ON \
  -DWIRELINK_ASIO_INCLUDE_DIR=/absolute/path/to/asio/include \
  -DWIRELINK_WLC_EXECUTABLE=/absolute/path/to/matching-wlc
cmake --build /tmp/wirelink-docs-udp --parallel \
  --target udp_peer_client udp_peer_server
ctest --test-dir /tmp/wirelink-docs-udp --output-on-failure -R '^wirelink_udp_peer$'
```

## Put I/O and core work on the same owner

C owns the port, two `2053`-byte RX units and generated kernel; maximum datagram size is `2052` bytes. A thin C++ helper owns Asio socket/wait resources without creating an owner thread. Each pass services I/O, then steps the kernel.

`example_udp_wait` queries readiness/earliest deadline with `wl_kernel_ready`, subtracts elapsed work and invokes the adapter's latched wait. The server also limits waiting by the next 20-millisecond telemetry attempt. These clocks use milliseconds, unlike the RAM tutorials' loop ticks.

The same owner closes the kernel, stops the socket, steps and requires quiescence before freeing the helper. External workers, if added, must also exit. Read the [complete owner loop and helper sources](https://github.com/starwey604/wirelink/blob/main/docs/tutorial-integration.md), then substitute UART/USB using the [transport contracts](/wirelink/reference/transports/). For a board, follow [Zephyr peers](/wirelink/learn/zephyr-udp-subscriber/).
