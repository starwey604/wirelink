## Build the core first

From the Wirelink root, provide a C11 compiler and CMake 3.21+. The default loopback uses checked-in generated C, without WLC or hardware.

```sh
cmake -S . -B build/core -DCMAKE_BUILD_TYPE=Release
cmake --build build/core --parallel
ctest --test-dir build/core --output-on-failure
```

## Prepare WLC for your own messages

Generated tutorials/projects need matching Wirelink 0.13.0 and WLC 0.13.0 / contract 0.13. WLC is an independent source repository; Rust/Cargo builds that tool only:

```sh
cargo build --release --locked --manifest-path /path/to/matching-wlc/Cargo.toml
/path/to/matching-wlc/target/release/wlc --version
/path/to/matching-wlc/target/release/wlc codegen-contract
```

Expect `wlc 0.13.0` and `0.13`. Pass its absolute path as `WIRELINK_WLC_EXECUTABLE`. Host/desktop adapters also need C++20 and standalone Asio; Python SDK source builds need Python 3.10+ with development headers.

Continue with [telemetry](/wirelink/learn/getting-started/) or [RPC](/wirelink/learn/request-a-result/). The [installation guide](https://github.com/starwey604/wirelink/blob/main/docs/installation.md) owns platform prerequisites. Existing applications use [installed CMake integration](/wirelink/learn/external-cmake-project/).
