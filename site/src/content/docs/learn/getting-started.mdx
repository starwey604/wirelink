Send 12 ordinary messages and print `12 ordinary telemetry messages received; both endpoints quiescent`.

From the Wirelink root, use matching WLC 0.13.0 / contract 0.13. [Set up tools](/wirelink/learn/environment-setup/) first.

```sh
cmake -S . -B /tmp/wirelink-docs-tutorials -DCMAKE_BUILD_TYPE=Release \
  -DWIRELINK_BUILD_WLC_EXAMPLES=ON \
  -DWIRELINK_WLC_EXECUTABLE=/absolute/path/to/matching-wlc
cmake --build /tmp/wirelink-docs-tutorials --parallel \
  --target wirelink_telemetry_demo
ctest --test-dir /tmp/wirelink-docs-tutorials --output-on-failure \
  -R '^wirelink_telemetry_demo$'
/tmp/wirelink-docs-tutorials/examples/00_telemetry/wirelink_telemetry_demo
```

## Reuse the source after admission

`telemetry_kernel_send_telemetry` snapshots the value before `WL_OK`. The publisher clears its source immediately; the subscriber checks sample order and temperature inside a borrowed callback. To retain a value, copy it before returning. On `WL_ERR_WOULD_BLOCK`, keep the pending output in application storage and retry later.

The two C11 peers share one owner and RAM-copy loopback. One tick is one loop pass, not a millisecond. The owner advances both kernels and transport. Close stops retained transfers and steps both cores to quiescence.

Read the [publisher, subscriber and lifecycle explanation](https://github.com/starwey604/wirelink/blob/main/docs/getting-started.md). Next, [request an RPC result](/wirelink/learn/request-a-result/).
