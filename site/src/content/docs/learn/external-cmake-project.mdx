---
title: "Use the installed CMake package"
description: "Link an existing C application or generate typed routes."

---

Install the core from the Wirelink root, then consume it from a separate project containing your `main.c`. Configure the install prefix before building; this also gives `wirelink.pc` the correct prefix.

```sh
cmake -S . -B build/install-core -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_INSTALL_PREFIX=/absolute/prefix -DCMAKE_INSTALL_LIBDIR=lib
cmake --build build/install-core --parallel
cmake --install build/install-core
```

```cmake
cmake_minimum_required(VERSION 3.21)
project(my_device LANGUAGES C)
find_package(Wirelink 0.13.0 EXACT CONFIG REQUIRED)
add_executable(app main.c)
target_link_libraries(app PRIVATE Wirelink::wirelink)
```

```sh
cmake -S /path/to/my-device -B build/my-device \
  -DCMAKE_PREFIX_PATH=/absolute/prefix
cmake --build build/my-device --parallel
```

The base target requires only C. Optional host/adapter components need CXX and must be enabled in the installed build. For typed generation, set `WIRELINK_WLC_EXECUTABLE` to matching WLC 0.13.0 and use `wirelink_wlc_generate(TARGET ... SCHEMA ... PROFILE ...)`; codec-only projects use `wirelink_wlc_generate_codec`.

See the [installed-consumer commands](https://github.com/starwey604/wirelink/blob/main/docs/development.md#verify-an-installed-consumer) for pkg-config and generated/optional consumers. The [WLC guide](https://github.com/starwey604/wlc/blob/main/docs/codegen.md) explains imports and provenance.
