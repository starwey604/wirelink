Wirelink is an allocation-free C11 endpoint kernel. Generated code supplies typed routes and static capacities; ordinary messages and four concurrent RPC calls share the same core. Run it from an MCU loop, an RTOS task or a desktop owner.

## Start with your task

- **Run communication first:** [prepare the tools](/wirelink/learn/environment-setup/), run [telemetry](/wirelink/learn/getting-started/) and [RPC](/wirelink/learn/request-a-result/), then retain results and handle pressure/cancellation.
- **Connect your device:** follow the [kernel data flow](/wirelink/concepts/kernel/), then bind a driver using the [UART, USB and UDP contracts](/wirelink/reference/transports/).
- **Change the library or generator:** use the [development guide](/wirelink/development/contributing/) to find the owning source layer and decisive checks.

## Integrate as needed
