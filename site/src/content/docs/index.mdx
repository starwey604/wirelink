Wirelink 0.13 uses an allocation-free C11 static endpoint kernel. Applications supply storage, one owner, monotonic time and a transport. Ordinary messages and four-call RPC share one core; applications define retries, idempotency and jobs. Automatic ARQ, replay and deferred execution were removed.
