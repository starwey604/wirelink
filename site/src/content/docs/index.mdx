Wirelink is an allocation-free C11 protocol engine for two endpoints connected by
a serial, packet, or application-provided transport. Start with a localhost
example, then carry the same message model to firmware.

<CardGrid>
  <Card title="Prepare once" icon="add-document">

  </Card>
  <Card title="Keep resource use bounded" icon="setting">

    own threads, a heap, hardware, or a clock.
