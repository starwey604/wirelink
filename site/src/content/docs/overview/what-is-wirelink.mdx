> The full version of this page is currently maintained in Simplified Chinese: [什么是 Wirelink](/wirelink/zh-cn/overview/what-is-wirelink/).

Wirelink pairs a deterministic, zero-heap ISO C11 kernel (`src/`) with a Rust schema compiler (`wlc/`) that compiles `.wl` schemas and `.bind.wl` profiles into static C endpoints and Python/C++20 host SDKs.

- Read the engineering entry point in [docs/README-en.md](https://github.com/starwey604/wirelink/blob/main/docs/README-en.md).
