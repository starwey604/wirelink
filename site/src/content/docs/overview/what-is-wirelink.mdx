Use Wirelink when a device and its peer exchange typed messages/RPC and you need to choose memory, timing and transport explicitly. The portable core is ISO C11 and owns no heap, clock, thread or driver.

Write messages in `.wl` and choose routes/connector in profile version 2. WLC generates codecs, typed routes and bounded storage around the shared C kernel. Firmware and C++/Python clients use the same communication contract.

- **Messages:** send telemetry or events, and copy any callback data you need to keep.
- **RPC:** admit up to four outbound calls per endpoint; short handlers return a response or signed business status.
- **Application work:** define retries, idempotency, latest values and long jobs in your own state.

Start with [telemetry](/wirelink/learn/getting-started/) or [RPC](/wirelink/learn/request-a-result/). For physical I/O, choose [transport integration](/wirelink/reference/transports/). To understand ownership first, follow [the kernel](/wirelink/concepts/kernel/).
